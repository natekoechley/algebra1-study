## 🟢 The Big Idea (ELI5)

**The Zero Product Property:** If two things multiply to give ZERO, at least one of them MUST be zero.

If `(A)(B) = 0`, then `A = 0` or `B = 0`. There's no other way.

So to **solve** a quadratic equation:
1. Get one side equal to zero.
2. Factor the other side.
3. Set each factor equal to zero.
4. Solve each — those are your answers.

Example: `(x − 3)(x + 5) = 0`
→ Either `x − 3 = 0` → x = 3
→ Or `x + 5 = 0` → x = −5
**Solutions: x = 3 or x = −5.**

| **Solve** | Find values of x that make the equation true |
| **Solutions / roots / zeros / x-intercepts** | All the same thing here — the x-values where the quadratic equals zero |
| **Set equal to zero** | Move everything to one side so the other side is 0 |

## 🧾 The Recipe

For a quadratic equation `something = something`:

1. **Move everything to one side** so the equation = 0.
2. **Factor** the side with the polynomial (use Topics 3–6 as needed).
3. **Set each factor equal to zero** separately.
4. **Solve each mini-equation** for x.
5. **Write both solutions.** (Quadratics usually have 2.)
6. **Optional check:** plug each solution back into the original equation.

---

## ✏️ Worked Example

**Solve:** `x² + 5x − 14 = 0`

Step 1: Already = 0. ✓
Step 2: Factor `x² + 5x − 14`. Need two numbers that multiply to −14 and add to 5 → +7 and −2.
→ `(x + 7)(x − 2) = 0`
Step 3: Set each factor = 0:
- `x + 7 = 0` → **x = −7**
- `x − 2 = 0` → **x = 2**
Step 4: Solutions: **x = −7 or x = 2**
Step 5: Check: plug x = 2 → (2)² + 5(2) − 14 = 4 + 10 − 14 = 0 ✓

---

## ✏️ Worked Example #2 (with rearranging)

**Solve:** `x² + 3x = 10`

Step 1: **Move 10 over** → `x² + 3x − 10 = 0`
Step 2: Factor: two numbers ×−10 +3 → +5 and −2.
→ `(x + 5)(x − 2) = 0`
Step 3: x = −5 or x = 2 ✅

---

## 🧠 Mnemonic — "ZEROS: Zero out, Factor, Each = 0, Solve"

**Z**ero one side. **F**actor. **E**ach factor = 0. **S**olve.

Or simpler: **"Equation must equal zero before you can factor to solve."**

---

## ⚠️ Common Traps

1. **Skipping the "set to zero" step.** You CANNOT factor `x² + 3x = 10` directly and say `x(x + 3) = 10` so `x = 10` or `x + 3 = 10`. **THIS IS WRONG.** Only works when right side is **0**.
2. **Forgetting one solution.** Quadratics usually have 2 solutions. If you only write one, you missed the other factor.
3. **Sign mistakes when solving each factor.** `x − 5 = 0` means `x = +5`, not −5.
4. **Trying to solve without factoring first.** If you can't factor, this method doesn't work — use Topic 11, 12, or 13 instead.

2. `x² − 7x + 12 = 0`

4. `x² + 2x = 15` (rearrange first!)
5. `2x² − 5x − 3 = 0` (advanced factoring)

---

## ✅ Answers

1. x = 3 or x = −4
2. Factor: (x−3)(x−4) → x = 3 or x = 4
3. Factor: (x+6)(x−1) → x = −6 or x = 1
4. Rearrange: x² + 2x − 15 = 0. Factor: (x+5)(x−3) → x = −5 or x = 3
5. AC method: ac = −6, need ×−6 +(−5) → +1, −6. Split: 2x² + 1x − 6x − 3 = x(2x+1) − 3(2x+1) = (2x+1)(x−3) → x = −½ or x = 3

(If you got 4 or 5 right → ✓ done.)

## 👨 Nate's Tutor Primer

**This is the bridge between factoring and solving.** Once factoring is solid, this method is mostly bookkeeping.

When co-working:
- **The "zero" reflex is the whole trick.** When she sees a quadratic equation, the first move should be: "Is the right side zero? If not, move everything left."
- **Drill the WRONG way to show why it doesn't work.** Have her try `x(x+3) = 10` → "if I say x=10, does that work? Let's check: 10(10+3) = 130. Nope!" Showing the failure makes the rule stick.
- **The 2-solution rule** — Always check: "Did I write both solutions?"
- **Connect back to factoring topics.** If she struggles to factor in Step 2, she's struggling with Topic 4/5, not Topic 10.

**"New math" note:** Same as before. The phrase "Zero Product Property" is universal. Some teachers also call it "ZPP."

**Big test tip:** When the problem asks "find the x-intercepts" of a graphed parabola written as a function — that's the SAME thing as solving the equation = 0. The x-intercepts of `y = x² + 5x − 14` are the solutions to `x² + 5x − 14 = 0`. Same problem, different wording.
