# How to Import the Flashcards into Quizlet

You have 3 CSV files in this folder ready to import:
- `flashcards-vocab.csv` — 40 vocabulary terms
- `flashcards-formulas.csv` — 22 core formulas
- `flashcards-traps.csv` — 15 "spot the trick" cards

---

## Steps to Import (takes ~2 minutes per deck)

1. Go to **https://quizlet.com** and log in (or create a free account).
2. Click the **`+ Create`** button (top right).
3. Click **"Flashcard set"**.
4. Give it a title — e.g., "Math Crash Course — Vocab".
5. Below the title bar, click **"+ Import from Word, Excel, Google Docs, etc."**.
6. **Open the CSV file** in your text editor (or Numbers / Excel / Google Sheets).
7. **Copy all the rows** (including the header row is fine — you'll skip it next).
8. **Paste** into the Quizlet import box.
9. Under "Between term and definition" select **Comma** (`,`).
10. Under "Between rows" select **New line**.
11. Click **Import**. You should see all your flashcards populate.
12. Delete the first row if it shows up (it's the header — "Term, Definition").
13. Click **Create** at the top right. Done!

---

## Pro Tips

- **Run all 3 decks separately** — easier to study one type at a time.
- **Use "Learn" mode** in Quizlet — it adapts to which cards you miss.
- **Use "Match" game** for quick warm-ups — feels like a game, builds speed.
- On phone: install the Quizlet app for offline access.
- **5 minutes a day** with the flashcards = huge confidence boost on the test.

---

## Suggested Study Cadence

- **Daily:** 5 min on vocab + formulas (after the topic session).
- **Twice weekly:** 5 min on traps (especially the day before mini-quizzes).
- **Day before test:** Quick run through all 3 decks in "Match" mode.

## Alternative: Free Web-Based Tools

If you don't want to use Quizlet, the same CSV files work with:
- **Anki** (free, more powerful spaced repetition): https://apps.ankiweb.net
- **Brainscape**: https://www.brainscape.com
- Or just open the CSVs in Google Sheets and quiz each other from there!
