## 🟢 The Big Idea (ELI5)

A **parabola** is a U-shaped curve. You make one whenever you graph `y = x²` or anything with an `x²` in it.

The simplest parabola is `y = x²` — a smooth U sitting at the origin, opening upward.

Everything you'll do in graphing topics (7, 8, 9) is variations of that U: moving it up/down, left/right, flipping it upside-down, stretching it, squishing it.

This topic = **what the U looks like**, controlled by `a` in `y = ax²`.

---

## 📖 Vocab You Need (super important — used in all 3 graphing topics)

| Word | What it means |
|------|---------------|
| **Parabola** | The U-shaped curve made by a quadratic |
| **Vertex** | The very tip of the U — highest or lowest point |
| **Axis of symmetry (AOS)** | The vertical line through the vertex — the parabola is mirrored on each side |
| **Opens up** | U-shape (smile) — happens when a > 0 |
| **Opens down** | Upside-down U (frown) — happens when a < 0 |
| **Minimum** | The vertex y-value when parabola opens up (lowest y) |
| **Maximum** | The vertex y-value when parabola opens down (highest y) |
| **Domain** | All x-values that work → **always "all real numbers"** for quadratics |
| **Range** | All y-values that occur → depends on the vertex and direction |

---

## 🧾 The Recipe — Graphing y = ax²

1. **Plot the vertex** at the origin (0, 0). For `y = ax²` with no extras, the vertex is always (0, 0).
2. **Decide the direction:**
   - a > 0 → opens **up** (smile)
   - a < 0 → opens **down** (frown)
3. **Decide the width:**
   - |a| > 1 → **narrower** than y = x² (stretches up)
   - |a| < 1 (like a = 1/2) → **wider** than y = x² (flattens)
   - |a| = 1 → standard
4. **Make a small table of values.** Pick x = −2, −1, 0, 1, 2. Plug into y = ax².
5. **Plot the points and draw a smooth U through them.**
6. **Label** the vertex and axis of symmetry (x = 0 for this basic case).

## ✏️ Worked Example

**Graph:** `y = 2x²`

| x | y = 2x² |
|---|---------|
| −2 | 8 |
| −1 | 2 |
| 0 | 0 ← vertex |
| 1 | 2 |
| 2 | 8 |

- Plot the 5 points: (−2,8), (−1,2), (0,0), (1,2), (2,8).
- Draw a smooth U.
- Vertex: (0, 0). Axis of symmetry: x = 0. Opens up. Narrower than y = x² because a = 2.

## 🧠 Mnemonic — "Smile or Frown, Then Stretch"

- **a > 0 = smile 🙂** (positive feelings = opens up)
- **a < 0 = frown 🙁** (negative = opens down)
- **|a| big = skinny** (think tall narrow person — they have a "big personality")
- **|a| small = wide** (mellow, spread out)

For axis of symmetry of basic `y = ax²`: **always x = 0.** (The y-axis itself.)

## 📐 The ax² Heights Pattern (NEW — per Raj, May 2026)

From the vertex, the heights of the parabola at 1, 2, 3 steps left/right follow a clean pattern:

| Steps from vertex | Height (y-jump from vertex) |
|---|---|
| ±1 | a · 1 = **a** |
| ±2 | a · 4 = **4a** |
| ±3 | a · 9 = **9a** |

So for **y = x²** (a = 1): heights are **1, 4, 9.**
For **y = 2x²** (a = 2): heights are **2, 8, 18.**
For **y = ½x²** (a = ½): heights are **0.5, 2, 4.5.**

This shortcut works for **every parabola** — Topics 7, 8, 9, and 14 all use it once you've found the vertex. Memorize **1, 4, 9** as the parent pattern and just multiply by `a`.

## ⚠️ Common Traps

1. **Forgetting the negative pairs.** When x = −2, x² = +4 (negative squared is positive). Easy to miscompute.
2. **Confusing "wider" and "narrower."** Coefficient bigger = thinner (counter-intuitive!).
3. **Not labeling the vertex.** Always label it on a graph for full credit.
4. **Drawing a V instead of a U.** Parabolas are **smooth curves**, not pointed. The vertex is a rounded bottom (or top).

## 🎯 Practice Problems (do all 5)

For each, find: (a) vertex, (b) axis of symmetry, (c) opens up or down, (d) wider or narrower than y = x², and (e) the y-value when x = 2.

1. `y = x²`
2. `y = 3x²`
3. `y = −x²`
4. `y = ½x²` (also written y = 0.5x²)
5. `y = −2x²`

---

## ✅ Answers

1. Vertex (0,0), AOS x=0, opens **up**, **same** as y = x², y(2) = **4**
2. Vertex (0,0), AOS x=0, opens **up**, **narrower**, y(2) = **12**
3. Vertex (0,0), AOS x=0, opens **down**, **same width**, y(2) = **−4**
4. Vertex (0,0), AOS x=0, opens **up**, **wider**, y(2) = **2**
5. Vertex (0,0), AOS x=0, opens **down**, **narrower**, y(2) = **−8**

(If you got 4 or 5 right → ✓ done.)
