# Topic 11 — Solving Quadratics by Taking Square Roots
**Textbook:** Big Ideas Math, Algebra 1, Section 9.3
**PDF in folder:** `Algebra 2 - downloaded class files/cc19_algebra1_ipe_09_03.pdf`
**Time to learn:** 15–20 min

---

## 🟢 The Big Idea (ELI5)

If an equation looks like **`(something)² = a number`**, take the square root of both sides — but **don't forget the ± sign**.

`x² = 25` → take √ of both sides → `x = ±5` (both +5 and −5 squared give 25).

This is the **fastest** way to solve a quadratic when it's already in this clean form. It's a one-step method.

---

## 📖 Vocab You Need

| Word | What it means |
|------|---------------|
| **Square root** | The opposite of squaring. `√25 = 5` because 5² = 25. |
| **±** | "Plus or minus" — means there are TWO answers, one positive and one negative |
| **Perfect square** | A number whose square root is whole: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100 |
| **Irrational** | Square roots that aren't whole numbers, like √2 ≈ 1.414. Sometimes left in "exact form" as √2. |

---

## 🧾 The Recipe

For an equation that looks like **`(stuff)² = number`**:

1. **Isolate the squared part.** Get it alone on one side.
2. **Take the square root of both sides.**
3. **Add ± on the right side.** (Two answers.)
4. **Solve for x.**
5. **Simplify** if needed (especially if the square root isn't whole).

---

## ✏️ Worked Example #1

**Solve:** `x² = 49`

Step 1: Already isolated.
Step 2: √(x²) = √49 → x = ±7
Step 3: **x = 7 or x = −7** ✅

---

## ✏️ Worked Example #2 (with a wrapper)

**Solve:** `(x − 3)² = 16`

Step 1: Already isolated.
Step 2: √((x−3)²) = √16 → x − 3 = ±4
Step 3: Two equations:
- x − 3 = 4 → **x = 7**
- x − 3 = −4 → **x = −1**

Solutions: **x = 7 or x = −1** ✅

---

## ✏️ Worked Example #3 (needs isolation first)

**Solve:** `2x² − 8 = 0`

Step 1: Isolate x²:
- Add 8: `2x² = 8`
- Divide by 2: `x² = 4`

Step 2: √: x = ±2
Step 3: **x = 2 or x = −2** ✅

---

## 🧠 Mnemonic — "Don't Forget Plus-Or-Minus"

When you take a square root in an equation, **always write ±**. The most common error here is writing only the positive answer.

**Phrase to say out loud:** "Square root means PLUS OR MINUS."

---

## ⚠️ Common Traps

1. **Forgetting the ± sign.** Half-credit error. **Always two answers** (unless the right side is 0).
2. **Trying this on the wrong type of problem.** Only works when you can isolate `(stuff)² = number`. If there's a middle term (like `x² + 5x − 6 = 0`), this method doesn't work — use Topic 10 or 13.
3. **Square root of a negative number** = no real solution. `x² = −9` has no real answer.
4. **Forgetting to simplify radicals.** `x² = 12` → x = ±√12 = ±2√3 (simplify by pulling out perfect squares).
5. **For `(x − 3)² = 16`** — DON'T expand the left side first! That defeats the purpose. Take √ directly.

## 🎯 Practice Problems (do all 5)

1. `x² = 81`
2. `x² − 36 = 0`
3. `3x² = 75`
4. `(x − 2)² = 9`
5. `(x + 5)² = 49`

---

## ✅ Answers

1. x = ±9 → **x = 9 or x = −9**
2. Add 36: x² = 36 → **x = ±6**
3. Divide by 3: x² = 25 → **x = ±5**
4. √: x − 2 = ±3 → x = 2 + 3 = **5** OR x = 2 − 3 = **−1**. So x = 5 or x = −1.
5. √: x + 5 = ±7 → x = −5 + 7 = **2** OR x = −5 − 7 = **−12**. So x = 2 or x = −12.

(If you got 4 or 5 right → ✓ done. **If you forgot the ± anywhere, redo those tomorrow.**)

## 👨 Nate's Tutor Primer

**This method is the easy one** — but it only works for a specific form. Esme needs to **recognize when to use it**, not just how.

When co-working:
- **The recognition skill:** show her 5 equations and ask "square root method, yes or no?" Examples:
  - `x² = 25` ✓
  - `(x − 4)² = 9` ✓
  - `x² + 3x = 5` ✗ (middle term — use Topic 13)
  - `2x² = 50` ✓ (after dividing by 2)
  - `(x + 1)² − 8 = 0` ✓ (after adding 8)
- **Drill the ± reflex.** Make her write the ± symbol every single time, even on the line where she takes the square root. **Always say "plus or minus" out loud.**
- **For irrational answers** (`x² = 7` → x = ±√7), don't push decimal approximations unless the problem asks. "Exact form" is usually preferred.

**"New math" note:** Same method, same notation. The only modern twist is sometimes teachers prefer "**square root property**" as the formal name. Mr. Mistry might use either phrasing.

**Big test tip:** When she sees a vertex-form equation set to zero, like `2(x − 3)² − 8 = 0`, this is **always** a square-root-method problem. Watch for it. (Solve: add 8, divide by 2, take √, you get x = 3 ± 2.)
