# Algebra 1 — Quadratics Crash Course

A focused 19-day study kit for the core Algebra 1 quadratics curriculum (Big Ideas Math, chapters 7–9). Built for an ADHD + dyscalculia-aware learning style — short steps, repeatable recipes, lots of mnemonics, sign-discipline drilled everywhere.

**📐 [Open the interactive study site →](./index.html)**

The site has:
- Step-by-step recipe for each of 13 topics
- Interactive parabola visualizer (slide a / b / c, h / k, p / q — watch the graph change)
- Flashcards (vocab, formulas, traps)
- Topic quizzes
- **Practice generator: 3 fresh problems per topic on demand, each with a full step-by-step "show your work" solution**
- Searchable "I'm stuck" cheat sheet
- Panic mode (for when the brain freezes)

## Notes

This kit is built around the focused topic list from the teacher (Mr. Mistry) for a student preparing for a custom-built make-up test. All "top 10%" advanced material is intentionally excluded — the goal is rock-solid mastery of the core 80–90%.

Designed with ADHD and dyscalculia accommodations:
- 15–20 minute daily sessions, not marathons
- Recipes over explanations
- Sign-discipline drilled at every topic
- Built-in "panic mode" / "I'm stuck" pathways
- Always close on a problem the student got right

No tracking, no logins, no analytics, no third-party scripts. Just static HTML and Markdown — open it, study, close it.
