## 🟢 The Big Idea (ELI5)

You're multiplying two groups together — like `(x + 3)(x + 5)`.
**Every term in the first group has to shake hands with every term in the second group.** Then add the handshakes up.

Two ways to do it (same answer, different method):
- **FOIL** — for two-term × two-term (binomial × binomial). Quick.
- **Box Method** — works for *any* size, easier to track. Slower but bulletproof.

---

## 📖 Vocab You Need

| Word | What it means |
|------|---------------|
| **Binomial** | A polynomial with **2 terms**, like `(x + 3)` |
| **Trinomial** | A polynomial with **3 terms**, like `x² + 7x + 12` |
| **FOIL** | **F**irst, **O**uter, **I**nner, **L**ast — the order to multiply two binomials |
| **Like terms** | Same variable + same exponent (combines into one term) |

---

## 🧾 The Recipe — FOIL (for two binomials)

For `(a + b)(c + d)`:

1. **F** — Multiply the **First** terms: a · c
2. **O** — Multiply the **Outer** terms: a · d
3. **I** — Multiply the **Inner** terms: b · c
4. **L** — Multiply the **Last** terms: b · d
5. **Combine like terms** (usually the middle two).

## 🧾 The Recipe — Box Method (works for anything)

For `(x + 3)(x² + 2x + 5)`:

1. Draw a grid: 2 rows × 3 columns (one row per term in `(x + 3)`, one column per term in `(x² + 2x + 5)`).
2. Label rows and columns with the terms.
3. Multiply each row × column, write the product in the box.
4. **Combine like terms** by looking at all the boxes.

```
        x²       2x       5
      ┌──────┬───────┬───────┐
   x  │  x³  │  2x²  │  5x   │
      ├──────┼───────┼───────┤
   3  │ 3x²  │  6x   │  15   │
      └──────┴───────┴───────┘
```
Add everything: `x³ + 2x² + 3x² + 5x + 6x + 15` = `x³ + 5x² + 11x + 15` ✅

## 🧠 Mnemonic — "Everyone Shakes Hands"

Every term in the first group has to shake hands with every term in the second. No skipping.

For FOIL: **"Fast Old Italian Lemons"** (silly = sticky for ADHD brains).

For signs: **"The sign comes WITH the number."** `(x − 4)` is really `(x + (−4))`. Treat the −4 as one thing.

---

## ✏️ Worked Example (FOIL)

**Multiply:** `(x + 4)(x − 3)`

- **F**irst: `x · x = x²`
- **O**uter: `x · (−3) = −3x`
- **I**nner: `4 · x = 4x`
- **L**ast: `4 · (−3) = −12`

Combine: `x² − 3x + 4x − 12` = **`x² + x − 12`** ✅

---

## ⚠️ Common Traps

1. **Sign mistakes on Outer or Last.** When the second binomial has a minus, students drop it. `(x + 4)(x − 3)` Last = `4 · (−3) = −12`, not `+12`.
2. **Forgetting the middle terms exist.** `(x + 4)(x + 5)` is **not** `x² + 20`. It's `x² + 9x + 20`.
3. **Forgetting to combine like terms** at the end.
4. **`(x + 3)²` — common error:** It is **NOT** `x² + 9`. It's `(x + 3)(x + 3)` = `x² + 6x + 9`. **Square = multiply by itself, NOT distribute the exponent.**

## 👨 Nate's Tutor Primer

**The big risk** here is rushing FOIL and bungling signs. Slow her down.

When co-working:
- **Have her say out loud:** "First, outer, inner, last." Hearing it locks the sequence.
- **Always write all 4 terms before combining.** No mental math.
- **If signs trip her up, switch to the box method.** It's visually clearer for dyscalculia brains — you see each multiplication in its own box, can't lose track.
- For `(x − 3)²` and similar — **physically write it as `(x − 3)(x − 3)`** before starting. This eliminates the "x² + 9" mistake every time.

**"New math" note:** The box method (also called the "area model") is the modern preference because it generalizes to trinomials and beyond. You may have only learned FOIL. **Let her use the box method without judgment** — it's actually a better method for what comes later (factoring), so it's worth investing in.
