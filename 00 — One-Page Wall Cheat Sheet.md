## THE THREE FORMS OF A PARABOLA

| Form | Equation | What it shows you |
|---|---|---|
| **Standard** | y = ax² + bx + c | y-intercept = c. AOS = −b/(2a) |
| **Vertex** | y = a(x − h)² + k | **Vertex = (h, k)** — sign of h FLIPS! |
| **Intercept** | y = a(x − p)(x − q) | **Roots = p, q** — sign FLIPS! AOS = (p+q)/2 |

**a > 0 = smile ⌣ (opens up)**  ·  **a < 0 = frown ⌢ (opens down)**
**|a| big = skinny**  ·  **|a| small = wide**

## FACTORING PATTERNS

| Pattern | Factors to |
|---|---|
| Common factor in all terms | Pull out GCF first! |
| `x² + bx + c` | Find p, q where pq=c AND p+q=b → (x+p)(x+q) |
| `ax² + bx + c` | AC method: ×=ac +=b, split, group |
| `a² − b²` | (a + b)(a − b) |
| `a² + 2ab + b²` | (a + b)² |
| `a² − 2ab + b²` | (a − b)² |
| `a² + b²` | **DOES NOT FACTOR** |

## SOLVING METHODS (pick the right tool)

| Problem looks like | Use |
|---|---|
| Factors easily | **Solve by factoring** (set =0, factor, ZPP) |
| (stuff)² = N | **Square root method** (±√) |
| Asked to complete the square | **Completing the square** (half-square-add) |
| Anything else / not sure | **Quadratic Formula** (universal) |

### Quadratic Formula
**x = (−b ± √(b² − 4ac)) / 2a**

### Discriminant (b² − 4ac)
- **+** → 2 real solutions
- **0** → 1 real solution
- **−** → no real solutions

## TOP 10 TRAPS

1. `(x + 3)²` = x² + **6x** + 9, **not** x² + 9
2. Subtracting polynomials: flip **EVERY** sign
3. Vertex form: `(x − 3)` → h = **+3**; `(x + 3)` → h = **−3**
4. Intercept form: `(x − 5)` → root at **+5**, not −5
5. Square root: **always write ±**
6. Solve by factoring: **set = 0 FIRST**
7. `a² + b²` does **not** factor
8. AC method: multiply a·c first, **not** just c
9. Quad formula: write `(−5)²` not `−5²` for negative b
10. Always **label the vertex and AOS** on a graph

## VOCAB QUICK HITS

- **Vertex** = tip of the U (highest or lowest point)
- **AOS** = vertical line through vertex
- **Roots = zeros = x-intercepts** (three names, one idea)
- **Like terms** = same variable AND same exponent
- **GCF** = biggest term that divides all
- **Discriminant** = b² − 4ac (tells you # of solutions)
