## 🚨 Panic Card — Read This When You're Stuck

When the brain freezes, do this in order:

1. **Breathe.** Out longer than in. 3 times.
2. **Name the topic.** "This is a ___ problem." Open that recipe file.
3. **Copy the example.** Don't try to remember. Read the worked example, do yours the same way.
4. **Still stuck?** Skip. Move on. Come back. (Real test trick.)
5. **Text Nate.** Photo of the problem. He'll send back a hint, not the answer.

> **Esme's Rule:** Being stuck for more than 3 minutes = move on. Time is the enemy of confidence.

## Spaced Review (built in)

Before each new topic, spend **3 minutes** redoing one practice problem from a previous topic. The schedule covers this implicitly via the Mini-Quizzes and Mock Test, but the rule is:

> **Always start with one "I already know this" warm-up problem.** It primes the brain and builds momentum.
